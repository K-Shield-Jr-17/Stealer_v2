# Infostrealer

격리된 Windows VM 실습에서 파일 무결성 검증과 고정된 실행 순서를 분석하기 위한 런처 자료입니다. 네트워크 다운로드와 실행 파일 구동이 포함되므로 반드시 폐쇄된 실습망에서만 사용하세요.

## 파일 설명

- `lab_payload_runner.py`: 코드에 고정된 실습 서버와 파일 목록에서 payload를 내려받고, 각 파일의 SHA-256을 검증한 뒤 검증에 성공한 파일을 고정된 순서로 실행합니다. 리다이렉트 거부, 다운로드 크기 제한, 임시 파일 사용, 실행 로그 기록을 포함합니다.
- `dist/a.exe`: `lab_payload_runner.py`를 패키징한 콘솔 없는 Windows 실행 파일입니다.
- `a.spec`: PyInstaller 패키징 설정입니다.
- `build/`: 패키징 과정에서 생성된 중간 산출물입니다. 소스 파일이나 검증 기준으로 사용하지 마세요.

## 실행 전제

- Windows VM, 전용 실습망, 스냅샷 복구 지점이 필요합니다.
- 런처가 참조하는 파일과 해시가 실습 환경의 승인된 테스트 파일과 일치하는지 먼저 검토하세요.
- Python 분석 시 프로젝트 전용 가상환경을 사용하며, 실제 서버 주소나 payload로 설정을 바꾸지 마세요.
- 실행 결과와 로그는 `C:\Windows\Temp\Kisec\payloads` 아래에 남을 수 있습니다.

## 관찰 포인트

해시 검증 전 실행 방지, 리다이렉트 차단, 크기 제한, `.part` 임시 파일 정리, 고정된 실행 순서와 실패 처리 흐름을 확인할 수 있습니다.

## 안전 주의

이 런처는 파일을 내려받아 실행하므로 실습 범위를 벗어나면 안 됩니다. 인터넷 연결이나 개인 시스템에서 실행하지 말고, 네트워크 캡처와 프로세스 모니터링은 승인된 VM에서만 수행하세요. 실습 후 VM을 복원하고 결과 파일을 삭제하세요.
