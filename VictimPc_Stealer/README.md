# VictimPc Stealer 

Windows 파일 탐색 및 로컬 복사 동작을 분석하기 위한 교육용 자료입니다. 이름과 동작상 민감 정보 수집에 해당할 수 있으므로, 개인 PC가 아닌 폐쇄된 가상환경에서 합성 테스트 파일만 사용하세요.

## 파일 설명

- `FileStealer.py`: 현재 사용자 홈 디렉터리를 순회하면서 문서 확장자(`hwp`, `docx`, `xlsx`, `pptx`, `pdf`, `txt`, `csv` 등)의 파일을 `C:\Windows\Temp\Kisec`에 복사합니다. 이어서 기본 Chrome 프로필 디렉터리도 같은 목적지 아래에 복사하려고 시도합니다.
- `FileStealer.exe`: 위 Python 파일을 Windows 실행 파일로 패키징한 결과물입니다.

## 실행 전제

- Windows 가상머신과 실습용 테스트 계정이 필요합니다.
- Python으로 분석할 때는 프로젝트 전용 가상환경을 사용하세요. 외부 패키지는 필요하지 않습니다.
- 실행 전 테스트 파일만 들어 있는 별도 홈 디렉터리 또는 스냅샷을 준비하고, 실행 후 `C:\Windows\Temp\Kisec`의 생성 결과를 확인하세요.

## 관찰 포인트

홈 디렉터리 순회, 확장자 기반 필터링, 상대 경로를 파일명으로 평탄화하는 방식, `copy2`와 `copytree`의 차이, 권한 오류 처리 흐름을 살펴볼 수 있습니다.

## 안전 주의

이 코드는 문서와 브라우저 프로필을 복사하므로 실제 환경에서 실행하면 개인정보와 인증 자료가 노출될 수 있습니다. 실사용 계정, 실제 문서, 실제 브라우저 프로필, 운영체제의 공유 위치에는 사용하지 마세요. 실습이 끝나면 VM을 폐기하거나 스냅샷을 복원하세요.
