# Stealer - ClickFix 기반 침해사고 대응 및 분석 시뮬레이션 프로젝트

**K-Shield Junior 17기 2조 Project** ｜ 기간: 2026.09.01 ~ 2026.09.17

## 1. 프로젝트 소개

본 프로젝트는 **폐쇄형 VM(가상머신) 환경**에서 진행되는 침해사고 대응(Incident Response) 및 디지털 포렌식 분석 교육을 위해 구성된 시뮬레이션 프로젝트입니다.

ClickFix(가짜 캡차/오류 안내 등으로 사용자가 직접 악성 명령을 실행하도록 유도하는 사회공학적 기법)를 초기 침투 지점으로 삼아, 이후 이어지는 정보 수집 → 내부망 이동 → 데이터 수집 → 외부 전송(C2)까지의 다단계 공격 흐름을 폐쇄망에 안전하게 재현합니다. 분석가는 각 단계에서 시스템에 남는 로그와 아티팩트를 직접 확인하며 침해사고 분석 절차를 학습할 수 있도록 설계되었습니다.

> ⚠️ 본 프로젝트는 교육 목적의 시뮬레이션이며, 실제 악성 행위나 공격 대상 시스템 침해를 위한 도구가 아닙니다. 사용된 악성코드는 실제 위협(Lumma Stealer 등)의 공격 흐름을 참고하여 자체 설계한 분석용 재현 코드이며, 자격증명 탈취·탐지 회피 등 실제 악성코드의 핵심 기능은 구현하지 않았습니다.

## 2. 프로젝트 목적

- 단순 샘플 분석·이론 학습을 넘어, 초기 침투부터 악성 행위 수행, 대응팀의 탐지·분석에 이르는 침해사고 전 과정을 직접 설계·재현하여 DFIR(Digital Forensics & Incident Response) 실무 역량 확보
- 악성코드의 자체 설계·구현과 탐지 로직 수립을 함께 수행하여, 공격 기법과 방어 메커니즘을 동시에 이해하는 공격/방어 통합 관점의 분석 역량 강화
- 침해사고 대응 보고서, 악성코드 분석 보고서, LAB 기반 챌린지 등 구체적인 산출물을 제작하여 분석 결과의 체계적 문서화 및 기술 커뮤니케이션 역량 확보
- 동일한 초기 환경을 재현 가능한 배포형 LAB으로 구성하여, 반복 학습 및 외부 공개(GitHub) 기반의 DFIR 교육 환경으로 확장

## 3. 전체 침해사고 시나리오 개요

본 프로젝트가 재현하는 공격 흐름은 다음과 같습니다.

| 단계 | 개요 | 관련 구성 요소 |
|---|---|---|
| ① 초기 침투 유도 | 피싱 메일 또는 위장 사이트 노출을 통해 사용자를 ClickFix 페이지로 유도하고, 안내에 따른 명령 실행을 유발 | `ClickFix_Web` |
| ② 실행 및 감염 | 사용자가 실행한 명령을 통해 모의 InfoStealer가 다운로드·실행됨 | `C2_EXE` |
| ③ 시스템 정보 수집 | 감염된 Victim PC의 시스템·사용자 환경 및 네트워크 정보를 탐색·수집 | `Infostrealer`, `Network_Stealer` |
| ④ 내부망 이동 및 데이터 접근 | 확인된 권한을 바탕으로 Victim PC 및 사내 File Server의 문서·자산 파일 탐색 | `VictimPc_Stealer`, `FileServer_Stealer` |
| ⑤ 데이터 수집 및 외부 전송 | 수집 대상 파일을 정리(Staging)하여 LAB 내 모의 공격자 서버로 전송 | `C2_EXE` |
| ⑥ 탐지·분석 | 분석가가 각 단계에서 생성된 프로세스·파일·레지스트리·네트워크 아티팩트를 수집·분석하여 감염 흐름을 재구성 | 전체 모듈 공통 |

모든 시나리오에 사용되는 문서·자산 데이터는 실제 개인정보·기밀정보를 포함하지 않는 `Dummy_Data`(내용이 비어 있는 HWP, PPT, XLSX 등)로 구성됩니다.

## 4. 프로젝트 구성

| 구성 요소 | 역할 |
|---|---|
| **ClickFix_Web** | 사용자 행위 유도를 위한 시뮬레이션 웹 페이지. 초기 침투 단계의 사용자 상호작용을 재현 |
| **VictimPc_Stealer** | Victim PC에서 발생하는 파일 접근 및 수집 행위를 재현하는 실습 모듈 |
| **FileServer_Stealer** | 파일 서버 환경에서 발생하는 데이터 접근 행위를 재현하는 실습 모듈 |
| **Infostrealer** | 감염된 시스템의 정보 수집 행위를 재현하는 실습 모듈 |
| **Network_Stealer** | 네트워크 관련 정보 수집 및 분석 증적 생성을 위한 모듈 |
| **C2_EXE** | 침해사고 시나리오에서 사용하는 테스트용 구성 요소 |
| **Dummy_Data** | Victim PC 및 File Server 분석을 위한 더미 데이터 |

## 5. 디렉터리 구조

```
Stealer/
├── ClickFix_Web/           # 사용자 행위 유도 시뮬레이션 웹 페이지
├── VictimPc_Stealer/       # Victim PC 파일 접근/수집 실습 모듈
├── FileServer_Stealer/     # File Server 데이터 접근 실습 모듈
├── Infostrealer/           # 시스템 정보 수집 실습 모듈
├── Network_Stealer/        # 네트워크 정보 수집 실습 모듈
├── C2_EXE/                 # 시나리오 테스트용 구성 요소
├── Dummy_Data/             # 실습/분석용 더미 데이터
│   ├── VictimPc_Data/      # Victim PC 분석용 더미 파일
│   └── FileServer_Data/    # File Server 분석용 더미 파일
└── README.md
```

각 구성 요소 디렉터리에는 해당 모듈에 대한 별도 README.md가 포함되어 있어, 세부 설명을 참고할 수 있습니다.

## 6. 실습 환경

전체 LAB은 역할에 따라 세그먼트를 분리한 가상 네트워크로 구성되며, VMware Workstation의 Snapshot 기능을 활용해 모든 참가자가 동일한 초기 상태에서 반복적으로 분석·실습할 수 있도록 합니다.

| 네트워크 | 역할 | 구성 VM |
|---|---|---|
| 외부/공격 시나리오망 | ClickFix 유도 및 공격 수행 환경 | Kali Linux(공격자), Ubuntu Server(ClickFix Web Server), Windows 10(Victim PC) |
| 내부 업무망 | 침투 이후 접근 대상이 되는 사내 자산 | Windows Server 2022(Active Directory / File Server) |

- Victim PC는 외부 시나리오망과 내부 업무망에 모두 연결되어, 초기 침투 이후의 내부 이동(횡적 이동) 흐름을 재현합니다.
- 모든 VM은 초기 구성 완료 시점의 스냅샷을 확보하여 동일 조건에서 반복 실습이 가능합니다.
- 실습·분석에는 다음과 같은 도구군을 활용합니다.
  - **환경 구성**: VMware Workstation, Windows 10, Windows Server 2022, Ubuntu Server, Kali Linux
  - **정적/동적 분석**: Die, IDA, Process Monitor, Process Explorer, Autoruns, Regshot, System Informer
  - **호스트·네트워크 포렌식**: Sysmon / Windows Event Log, Wireshark, Volatility, FTK Imager
  - **협업 및 배포**: Git/GitHub, Google Drive
- 인터넷 및 실제 운영망과 분리된 **폐쇄형 가상 환경**에서만 구성·실행되어야 하며, 실제 운영 시스템·개인 PC·공용 네트워크에서는 절대 사용하지 않습니다.

## 7. 분석 가능한 주요 증적

- ClickFix 페이지 접속 및 사용자 명령 실행과 관련된 웹·PowerShell 실행 로그
- 프로세스 생성·부모자식 관계, 파일 생성/수정, 레지스트리 변경 등 호스트 기반 아티팩트(Sysmon/Windows Event Log)
- 파일 시스템 접근 이력(탐색, 복사, 압축 등) 및 임시 폴더에 생성되는 결과물
- 시스템 정보 및 네트워크 정보 수집 흔적
- File Server 공유 폴더 접근 이벤트
- 감염 프로세스의 네트워크 연결 시도 및 C2 통신 관련 트래픽(Wireshark 패킷 분석)
- 메모리 이미지 기반 악성 프로세스 및 실행 흔적(Volatility)

분석 교육생은 위 증적들을 Windows 이벤트 로그, 파일시스템 타임라인, 메모리·네트워크 분석 도구를 활용해 직접 식별·해석하고, 이를 바탕으로 침해사고 Timeline과 IOC(침해지표)를 도출하는 훈련을 수행합니다.

## 8. 학습 목표

- 사회공학적 기법(ClickFix)을 포함한 침해사고의 공격 흐름을 단계별로 이해하고, 각 단계의 특징적 행위 패턴을 학습
- 파일 접근·정보 수집·내부 이동 행위가 시스템에 남기는 아티팩트를 식별하고 분석하는 능력 배양
- 수집한 로그·아티팩트를 기반으로 침해사고 Timeline을 재구성하고 IOC를 도출하는 훈련
- 탐지 로직 적용 전·후의 효과를 비교하여 공격 기법과 방어 메커니즘을 함께 이해
- 사고 대응 절차(탐지 → 초동 조치 → 분석 → 보고서 작성)를 실습을 통해 체득

## 9. 프로젝트 진행 범위

- 본 프로젝트는 **분석 교육 목적**의 시뮬레이션 범위로 한정되며, 실제 서비스나 운영 시스템에 대한 공격·침투·데이터 수집 행위는 포함하지 않습니다.
- 각 모듈은 사전에 구성된 폐쇄형 실습 환경 내에서만 동작하도록 설계되어 있습니다.
- 재현 코드는 실제 위협의 공격 흐름을 참고하되, 탐지·분석 용이성을 위해 난독화 등 탐지 회피 기법은 적용하지 않았습니다.
- 시나리오 및 아티팩트의 구체적인 세부 구성은 별도의 LAB 챌린지 형태로 공개됩니다.
- 시나리오 확장이나 신규 모듈 추가는 동일한 교육 목적과 안전 원칙 하에서만 진행합니다.

## 10. 주의사항

- 본 프로젝트의 모든 구성 요소는 **폐쇄형 VM 환경 외부에서 절대 실행하지 않습니다.**
- 실제 개인정보, 기업 기밀문서, 운영 시스템 자산에 대해 사용해서는 안 됩니다.
- 악의적인 목적으로 재가공하거나 변종을 제작하는 행위를 금지합니다.
- 재현 코드 및 시뮬레이션 웹 페이지 소스코드를 팀 승인 없이 외부(개인 블로그, SNS 등)에 공유하지 않습니다.
- LAB 환경은 인터넷 비연결 또는 격리된 네트워크(NAT/호스트 전용)에서만 구동하며, 실 운영망과 물리적으로 분리합니다.
- LAB 환경 외부로 유출이 의심되는 경우, 즉시 네트워크를 차단하고 스냅샷 기준으로 롤백합니다.
- 실습에 사용된 결과물(로그, 수집 파일, 통신 기록 등)은 실습 종료 후 안전하게 삭제하거나 VM 스냅샷을 복원합니다.
- 각 하위 모듈의 README.md에 명시된 개별 주의사항을 반드시 함께 확인합니다.
- 본 프로젝트는 승인된 교육/연구 목적으로만 사용되어야 하며, 그 외 목적의 사용은 허용되지 않습니다.
